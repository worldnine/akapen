# akapen クイックスタート

akapen は、エージェントのアウトプット（ファイル・チャットの両方）にターミナル上で赤ペンを入れ、コメントごと送り返すためのツールです。ファイルは一切書き換わりません。

このガイドでは、実際のレビューの流れを 3 つの入口に分けて説明します。キー一覧などの完全なリファレンスは [README.ja.md](../README.ja.md) にあります。

## 前提

```sh
cargo install akapen            # 本体
herdr plugin link <このリポジトリ>  # akp / ime プラグイン（herdr ユーザー向け）
```

- herdr を使わない場合、`--send-cmd` でコメントをファイルや任意コマンドへ渡せる
- 併用ツール [ashiato](https://github.com/worldnine/ashiato) は mtime 順のファイルピッカーである（任意）

## 入口 1: チャット出力に赤ペン（akp / reply モード）

エージェントがチャットに貼ったコード例や説明文 — ファイルに触れていない出力 — にコメントする、最も手軽な入口です。

1. herdr でエージェントと作業中に、コマンドパレットから `akp.open` を選ぶ（`akp.open-side` は横分割、`akp.open-float` はポップアップ）
2. エージェントの直近メッセージが akapen で開く。`]` / `[` で直近のメッセージを切り替えられる
3. ダメなところに `v` で範囲選択 → `c` でコメント → `s` で送信

送信形式は `> 引用` + コメントなので、文脈ごとエージェントに届く。複数コメントは番号付きリストになり、「順番に対応すべき指摘」として読み取られる。

ファイルを開かずに済むため、「この例は誤解を招く」「この段落は冗長」といったフィードバックをその場で返せる。

## 入口 2: ドキュメントのレビューループ（--send-agent）

エージェントが書いた設計書やドキュメントを添削する基本ループです。

```sh
ashiato . --open-cmd "akapen {} --send-agent"   # ピッカーで選んで開く
akapen doc.md --send-agent                       # 直接開く
```

### 最小キー

| キー | 動作 |
|---|---|
| `j` / `k` | カーソル移動（`v` 中は範囲選択） |
| `v` → `c` | 行を選択 → コメント |
| `s` | コメントをエージェントへ送信（成功するとコメント消去） |
| `r` | 外部変更を検知したら新稿をロード |
| `n` / `N` | 前回レビュー時（ベースライン）との差分を移動 |
| `←` / `→` | 過去の草稿へ / 現在へ（タイムマシン） |
| `a` | NOW でマーク承認、過去の世代でベースライン設定 |
| `l` | コメント一覧 |
| `Tab` | view ⇄ source 切替（source で差分の行内容を正確に確認） |
| `q` | 終了（未送信コメントがあると確認） |

### 一周の流れ

```
読む → v/c で印 → s で送る → エージェントが直す
  → ⚡ → r でロード → n/N で直しを確認 → まだ変なら c → 繰り返し
```

エージェントがファイルを編集するとタイトルに ⚡ が表示されます。`r` で新稿をロードすると、**緑 = 変わった場所・赤 = 消えた場所**のマーク付きで届きます。view モードで「どこが変わったか」を感じ、Tab で source モードに切り替えて行の内容を正確に見るのが定番です。

- 純粋な削除にカーソルを合わせると削除行が強調され、そのまま `c` で「削除されたベースラインの本文」を引用付きでコメントできる
- 再ロードを繰り返してもベースラインは動かない。指摘が一通り直ったら NOW で `a` を押してマークを承認する

## 入口 3: タイムマシン — 「この草稿のほうが良かった」

akapen は全草案（Git コミット + ローカルスナップショットの一本のタイムライン）を保持しています。

- `←` / `→` で過去の世代を、レンダリングされたまま閲覧できる（`t` で世代一覧）
- 過去の世代で行を選んで `c` → `s` すると、**そのリビジョンと当時の本文**がコメントに添えられて届く。「3 章はこの前の案のほうが良かった」と伝えるだけで、エージェントは正確にその版へ戻せる
- `a` を過去の世代で押すと、その世代を新しいベースラインにできる（「ここから先が未レビュー」という扱い）
- `l` のコメント一覧から過去のコメントを選ぶと、**そのコメントが書かれたリビジョンを復元してから**該当行へジャンプする。直し漏れの確認に使える

## 困ったとき

- 送信に失敗してもコメントは消えない。`s` で再送できる
- コメントを消したい場合は `d` でカーソル下のコメントを削除する。`y` ならコピーだけ行える
- 外部でファイルが変わったら、`r` でロード、`i` で無視を選べる
- Esc はキャンセル専用なので誤って抜ける心配はない。終了は `q`（`--esc-quit` で調整可）

## 次の一歩

- `e` で `$EDITOR` を開き、ファイルを直接編集できる（TUI は一時中断され、戻ると自動でリロード）。vim / nano / emacs / micro 等 `+N` 慣習対応エディタではカーソル行から開く
- `akapen doc.md --send-cmd 'akapen2hunk'` でコメントを hunk の diff ビューへ注入できる
- `--callback <cmd>` で終了時にシェルコマンドを実行できる（ピッカーに戻る等）
- `--reply` はファイルではなくチャット出力用のモードである（入口 1 の akp は内部でこれを使っている）
- macOS ではコメント入力中に自動で入力ソースを ASCII に固定できる（`--ime off|ascii|jp`、プラグイン `ime` 参照）

詳細な仕様は [README.ja.md](../README.ja.md)、設計メモは [internals.md](internals.md) を参照。
